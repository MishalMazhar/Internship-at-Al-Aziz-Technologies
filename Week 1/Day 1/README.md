# Day 1 — Hands-on Assignment

**Task:** Build a basic multi-section HTML webpage. Create navigation, content sections, and a footer.

## What I Built
**Orbit Log** — a mission-control themed dashboard concept, structured entirely in semantic HTML5:

- `header` with logo + `nav`
- `hero` section (intro + CTA)
- `about` section (mission statement)
- `missions` section — a `ul` of featured mission cards, each with an image and `alt` text
- `schedule` section — an HTML `table` listing upcoming launches
- `logbook` section — a full `form` (text, email, select, radio, textarea, submit button, all paired with `label`s)
- `footer`
